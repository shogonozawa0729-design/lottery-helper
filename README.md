# lottery-helper

抽選応募補助Chrome拡張の共通ルール置き場です。

- GitHub側にはサイトごとの操作ルールだけを保存します。
- 氏名・住所・電話番号・メールアドレス等の個人情報は保存しません。
- 個人情報は各Chromeプロファイルの `chrome.storage.local` に保存します。
- 最終の申込・送信・購入・確定操作は自動実行しません。

## ルール作成方針

- 原則として抽選ごとの固有URL・イベントID・フォームID・設問IDには固定しません。
- 店舗・サービスのドメイン、共通パス、項目ラベル、フォーム構造を使い、次回以降の抽選でも再利用できるルールを優先します。
- 固有IDを使わないと安全に判定できない場合のみ例外として使用し、後から共通化できる構造が確認できたら再利用型へ更新します。
- 商品を複数選択できるフォームでは、原則として選択可能な対象商品をすべて選択します。
- ログイン、CAPTCHA、本人確認、受取日など人の判断が必要な項目は手動のままにします。
- 最終の申込・送信・購入・確定ボタンは自動実行しません。

## Rules

- `rules/index.json` : ルール一覧とバージョン
- `rules/cloud-pass.json` : CLOUD PASS用ルール
- `rules/livepocket-pao-30th.json` : LivePocket共通応募者情報ルール
- `rules/google-forms-torecaplaza55-30th.json` : トレカプラザ55 Googleフォーム用ルール

# 抽選応募補助 v0.9.8

抽選URLの一括オープン、左から順のリロード、応募フォームのプロフィール入力、同意項目の補助を行うChrome拡張です。
最終の「送信」「応募」「購入」「確定」は自動実行しません。

## v0.9.8
- Google Formsの「姓のフリガナ」「名のフリガナ」を分離して入力します。
- 英字の姓・名でも、分割欄には姓/名をそれぞれ個別入力します。
- フルネーム補正: 姓・名が揃っている場合は片側だけの `fullNameExact` より「姓＋名」を優先します。

- Google Formsのcheckbox処理を本体1系統に統一。OFF→ONのみでトグル禁止。
- CustomForm（WonderGOO / 新星堂 / Ganryu系）を本体専用処理へ変更。
- CustomFormは本名、ひらがな氏名、住所、生年月日、メール、確認メール等を設問文脈から入力。
- 店舗選択と受取日は手動。
- 既存値は原則上書きしない。
- ③は現在選択中のタブを起点に、右側のタブだけを順番に処理。左側のタブは触りません。
- ②一斉リロードは従来どおり全Webタブを左から右へ処理。
- GitHubのJSONルールは毎回最新版を取得し、失敗時はキャッシュを使用。
- 本体バージョンと共通ルールバージョンをサイドバーに別表示。

更新方法は `UPDATE_INSTRUCTIONS.txt` を参照してください。
